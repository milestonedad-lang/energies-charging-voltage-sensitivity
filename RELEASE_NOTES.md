# Version 1.0.0

Initial public supporting research release for **Sensitivity of hourly voltage decisions to charging energy representations in distribution test feeders**.

Includes paired input matrices, mappings and flags, 188 saved scenario arrays, complete frozen analysis and source checkpoints, executable scripts, formal figure/table source data, documentation, citation metadata, reuse licenses and SHA-256 checksums.

The scientific archive and existing scientific assets retain the verified submission-package bytes. Public-release preparation adds repository documentation, browseable source copies, citation metadata and the author-selected licensing terms. Verification checks integrity and saved-array structure. A fresh physical-model rerun forms a separate reproduction activity.
