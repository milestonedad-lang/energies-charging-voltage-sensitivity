# Third-party sources and license scope

1. **UrbanEV** — IntelligentSystemsLab/UrbanEV, pinned commit 44f2aa0c8d89f192bce00bafb0def74a21b39c68. The original LICENSE is preserved verbatim as `UrbanEV_CC0_LICENSE.txt` and in the nested source checkpoint. It identifies CC0 1.0 Universal. Cite Li H, Qu H, Tan X, You L, Zhu R, Fan W (2025), UrbanEV: An Open Benchmark Dataset for Urban Electric Vehicle Charging Demand Prediction, Scientific Data 12:523, https://doi.org/10.1038/s41597-025-04874-4. Source bytes and timestamps are unchanged; the study's derived NPZ aligns matrices and adds synthetic mappings and audit flags. The study depositor is not the original UrbanEV data collector.

2. **Historical exploratory workbook** — The immutable nested input checkpoint also contains `Detailed network parameters.xlsx`. Attribution: Song (2024), Detailed network parameters.xlsx, figshare, https://doi.org/10.6084/m9.figshare.26354131.v1, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). The workbook is unchanged. Original Figshare metadata is preserved here. It was explored during feasibility checking and is not the 33/69-bus case data used in the final power-flow comparisons. No third-party article PDFs or full texts are included.

3. **MATPOWER** — Ray D. Zimmerman, Carlos E. Murillo-Sanchez and contributors; pinned official case sources specified in `source_data/grid_sources.json`. Case data source files are fetched from the original repository by the restoration script and are not redistributed as stand-alone files in this release. Follow their original headers/terms. Cite the MATPOWER paper and the original Baran–Wu case references listed in the manuscript. Our Python power-flow implementation is study code; no MATLAB/MATPOWER solver execution is implied.

The root `LICENSE` defines this scope for the outer repository and the study-authored members of frozen nested archives. Third-party source terms and attribution continue to apply to their respective files.
